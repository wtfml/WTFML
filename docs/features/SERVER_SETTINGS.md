# 服务端设置

本文说明如何修改服务端、选择世界和维护服务端文件。

- **概览**显示端类型、版本、连接地址、启动世界、玩家上限、MOTD 和服务端目录。运行状态、打开目录、控制台、启动与停止在页眉。
- **启动设置**保存此服务端的 Java 路径、最大内存和 JVM 参数，留空的 Java 路径与默认内存继承全局设置。
- **设置**用表单编辑 `server.properties`。文件中已有的其余键在「其他属性」中直接编辑。维护中的原始文本和世界页的启动世界共用待保存的配置。服务端准备启动时即锁定配置，停止后可重新编辑。
- **世界与玩家**的世界下拉框切换浏览、编辑及备份目标，选择「设为启动世界」才修改待保存的 `level-name`。编辑存档沿用客户端的世界规则与 `level.dat` 编辑器，写入前备份原文件。服务端启动和运行期间锁定世界选择与存档编辑。维度分目录的旧版服务端从世界页导出完整服务端备份。玩家下拉框切换白名单、管理员、封禁玩家和封禁 IP。
- **内容管理**的数据包针对世界页选中的世界。插件端显示插件，模组端显示模组，文件分别放入 `plugins/` 和 `mods/`。
- **维护**可检查并补全文件、读取最近的日志、编辑原始文本、导入或导出迁移包、创建同类型的升级副本。迁移包导入只创建新服务端。升级副本复制现有世界、名单和相关配置，并使用现有安装流程安装目标版本。
