## 1. 产品边界

- 桌面启动器，采用 C++23 + Qt 6 Widgets，目前只发布 Windows x64 版。
- **没有 `.ui` 文件**，界面全部手写。
- 界面层与核心层分工：实际存在少量双向引用（`ui/` 有 6 处 include `src/` 模型与控制器，`src/` 有 45 个文件 include `ui/` 头文件；复杂业务、网络与文件操作由 `src/` 和 controller 层承载）。
- 产品 exe 为 GUI 子系统，不弹控制台；stdout/stderr 默认不可见，诊断信息写入 `<数据目录>/logs/wtfml.log`。验证工程为控制台程序。
- 数据目录为当前选中的游戏目录，非 exe 所在目录。
- 启动器自身状态和账户表保存在注册表 `HKCU\Software\WTFML`；令牌使用 Windows DPAPI 加密后落盘。
- 不记录用户明文密码；不将令牌、私有路径或本地凭据写入仓库、日志或错误报告。
- 已加载的 Minecraft access token 在启动器日志、游戏输出面板与导出报告中按实际值遮盖；stdout/stderr 各自跨块过滤，进程结束时残留的令牌前缀同步遮盖。普通日志不按 JWT 外形误删。正版启动脚本运行时需通过环境变量 `WTFML_MC_ACCESS_TOKEN` 提供令牌，缺失或格式不安全则拒绝启动。
- 影响操作结果或需要用户决定的失败必须在界面可见，不能仅写日志；可选外观资源获取失败可降级显示，关键步骤失败必须明确报错。
- 进度、速度、剩余时间、兼容性或操作结果均基于真实状态展示，未知即显示未知，失败即显示失败。
- 文件操作遵循可恢复原则：先备份/暂存，再原子替换；失败时保留原状态或明确报告已写入部分。

## 2. 界面骨架与交互

### 主窗口

- 左侧导航轨：品牌、五项导航、底部任务进度与工具箱入口（点它直接进工具箱页；任务进度下方常驻运行状态入口，进程起停时轨上不增减元素、几何不变。点开是运行面板，每个进程一行（客户端、服务端合计），行尾有日志或控制台、设置、结束三个操作，新启动的在最上，面板贴着入口弹出。展开轨里入口是整格，空闲写「未运行」，有进程写「%1 个进程运行中」；图标轨里是一枚运行图标，有进程时右上角带进程数徽标（超过 99 写「99+」），空闲时图标弱化、不带数字，悬停提示「未运行」；空闲时点不开、不高亮，回车和空格不弹面板。Tab 可到，有进程时回车、空格打开。运行中的进程只在这里查看，任务中心里不再有「运行中的进程」一栏）；宽 208，可折成 64 的图标轨：每次启动都是收起的，点左上角 W 标展开 / 收起（只有 W 能点，键盘 Tab 到它按回车、空格也行，键盘焦点是 W 底下一笔主题色的手写下划线，不画框；窗口激活、鼠标关浮层或换页时交给 W 的焦点不画下划线，也不接回车、空格；悬停提示「展开导航」/「收起导航」）；窗口窄于 1024 时强制收起，点 W 不展开，提示「窗口加宽后才能展开」。顶上 40 高的拖动条带最小化、关闭，主窗口没有最大化也没有 Windows 贴靠（拖到屏顶 / 屏边 / 屏角不弹贴靠布局浮条、不贴半屏或四分之一屏，窗口停在松手的地方；Win+↑ / ← / → 无效；双击空白处、双击边框都不动），只能拖边、拖角缩放；游戏日志窗仍可最大化；标题文字可在设置中自定义，留空恢复默认。窗口里不在按钮、输入框、列表、可选文字上的空白处都能按住拖窗（主窗口自己搬动，不进系统移动循环；独立窗口仍走系统拖窗，贴边吸附照常）；游戏日志窗和各独立窗口同样，它们双击空白处最大化 / 还原。
- 窗口默认 1024×620，最小 900×590（最小高看工具箱「旗帜」页：585 起放得下，再留 5px 余量给缩放取整和字体回退）。记住上次关闭时的大小（只记大小不记位置），下次启动按它开，夹在最小尺寸和当前屏幕可用区之间；改大小停 0.4 秒就存一次，进程被杀最多丢最后一次改动。设置 › 个性化 › 外观「窗口大小 · 恢复默认」回到 1024×620 并在当前屏幕居中。
- 应用图标是「手写的 W」（无底）（`assets/app/`）：exe 文件本身（资源管理器、固定到任务栏）由 `res/wtfml.rc` 编进资源，运行中的窗口（任务栏、Alt+Tab）用 qrc 里 16/32/48/256 四档 PNG 铺给所有顶层窗口；自绘标题栏不挂窗口图标，导航轨左上角的品牌标画同一个 W（跟主题着色，暮色雪山用原色；收起轨时只留 W）。W 的颜色按它在主页风景和别的页磨砂底上都有 3:1 一次取定，换页不变色；品牌字同样不随页面换色，右上三颗窗口按钮的墨色跟主页风景 250ms 淡入淡出渐变；自定义背景图很亮时，按钮按实际压着的底往反差方向挪到至少 3:1（默认风景和三套主题观感不变）。
- 磨砂用 Win11 的系统背板（`DWMWA_SYSTEMBACKDROP_TYPE`：亚克力 3、云母 2），窗口里只铺一层半透明令牌色。系统默认只在窗口是「活动窗口」时画这层材质，一失焦就换成中性纯色（见 <https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic>）；本程序把每次 `WM_NCACTIVATE` 都按「激活」交给系统，DWM 便一直画激活态：**窗口失焦也保持模糊**，和聚焦时逐像素一样，客户区外那 1px 也不再变成一圈灰线。键盘焦点照常切换。设环境变量 `WTFML_KEEP_BACKDROP_ACTIVE=0` 回到系统默认（失焦退成纯色）。没有系统背板的系统（Win10 等）本来就落到风景底，不受影响。
- 着色层的 alpha 现算：取正文、次要字在背板可能落到的颜色（背后为纯黑、纯白和六个纯色时系统亚克力 / 云母合出来的颜色，按本机实测拟合，见 `ui/SystemBackdrop`）上都 ≥ 4.5:1 的最小值，「着色强度」只往上加（出厂 20%）。出厂时三主题都落在这个最小值：亚克力 / 云母档 暮色雪山 0.64、冰川碧湖 0.55、落日海崖 0.61；风景底档按模糊风景的明暗极值算，内置风景下 暮色雪山 0.51、冰川碧湖 0.71、落日海崖 0.73。
整窗铺主题场景图，开启「磨砂效果」时导航轨和面板为毛玻璃。
- 主体为「导航轨 + 一个正文面」架构：轨负责导航，正文区展示当前激活的主表面。
- 导航布局：同类独立功能使用可展开子项，内容较少的页面保留一级入口。
- 界面文案保持简洁、正式，直接说明操作与结果，不使用口语化叙述与中点分隔符。
- 主页、管理、下载、设置四个主选项卡；下载页和实例页内部包含各自的侧栏或分类栏。
- 下载页进入某个游戏版本的安装页（或服务端安装表单）后，顶部分类栏仅保留「游戏」与「服务端」两项，退出安装页返回版本列表时恢复全部分类；在游戏安装页点「服务端」直接打开同一版本的服务端安装表单，该版本无对应服务端时退回服务端版本列表并提示。
- 主页大标题下面一行「每日一言」：一天一句、单行小字，超宽省略号；悬停显示「— 作者《出处》」。语种按本地日期定（英文 60%，其余为一言的中文或日文），当天不变；当天有缓存就不再请求，连不上先显示句子池 / 内置兜底里那一句。中文用文楷、纯英文用 Dancing Script、含假名用系统日文字体。设置 → 个性化 → 外观可关，关掉不发请求也不占位。细节见 [DAILY_QUOTE.md](features/DAILY_QUOTE.md)。
- 主页：左上大标题是一句问候（规则在 `src/util/HomeGreeting.cpp`）：第一次打开（没有「上次打开日期」记录且一个实例都没有）写「欢迎来到 WTFML」；没记录但有实例算升级上来的老用户，按时段问候；距上次打开满 14 天写「好久不见 {名字}」；其余按本地钟点 05–10 早上好、11–12 中午好、13–17 下午好、18–22 晚上好、23–04 夜深了，写「{问候} {名字}」，不带标点。名字和右上账号胶囊同一来源，没登录不带名字（「晚上好」）。启动、换账号 / 登录 / 退出、窗口重新激活时重算，不挂定时器。单行，名字太长只截名字（「晚上好 ThisIsAVer…」），问候保留；问候用文楷 Light（窄窗 40、宽窗 50），和名字之间空 0.4 个字高。名字（和「WTFML」）按整段判字体：全是字母、数字、下划线用 Dancing Script，字号放大 1.2 倍、字距 0；带中文（纯中文或中英混写）整段用文楷，不按字拆成两种；两种字都没有的字落到系统楷体。左下是当前实例的启动区。实例名用文楷，字号随名字长短在 40–28 里取放得下整名的最大一号，到 28 还放不下才省略、悬停那一块看全名；行高按 40 预留，名字长短和窗口宽窄不挪下面的元信息行与按钮，拉宽拉窄、换当前实例都重挑。「名字 + 加载器与游戏版本」那一块可点，弹出毛玻璃实例切换弹层（顶部搜索、「最近」至多 5 个、「全部 · N」，底部「新建实例」去下载页、「管理全部实例」去管理页）；主按钮只做动作：启动游戏 / 停止游戏（当前实例运行时，使用电源图标）/ 安装中 N%，一个实例都没有时写「还没有实例」+「下载游戏」。点「启动游戏」后，主按钮和设置钮原地换成启动卡片（整块高度不变）：左边一枚手写 W 循环书写（25% 淡墨作底，一段浓墨沿笔画单向走，一圈 2.8 秒，首尾接成环不跳），中间是当前阶段「校验登录 / 检查文件 / 补全文件与资源 / 准备 Java / 等待游戏窗口」和进度条（补全文件写件数，下载 Java 写 MB，其余不定进度），右边「取消」（停掉这次启动，任务中心记「已取消」，卡片回到平常的启动区）。眉题换成「正在启动游戏」，元信息末项换成登录方式（离线登录 / 微软账号登录）。阶段与进度读任务中心那一项启动任务，两边说的是同一件事；游戏窗口出来才算启动完成（找不到窗口时等 2 分钟按首条输出算）。成功时 W 铺满停住、进度条走满（主题色），眉题「游戏已启动」，约 1.5 秒后回到平常的启动区；失败时 W 铺满后转灰，眉题「启动失败」（危险色），写原因和「停在「阶段」」，右边「查看详情」打开这次启动的任务详情、「关闭」回到启动区。同时启动几个实例时卡片只显示最近的一次；启动期间不再出忙指针，底栏也不再写「正在准备游戏文件…」。右侧是当前皮肤人物（皮肤未就绪时显示内置默认皮肤）。底部实例带只摆真实例（没挑图标的实例按名字固定配一种颜色的方块），分「最近 / 收藏」两页：点卡片设为当前实例，悬停出的播放钮直接启动；「管理」去管理页。页签那一排「最近 / 收藏」右边有一个箭头，直接画在风景上、不铺底：点它把卡片那一排收起或展开（悬停提示「收起最近与收藏」/「展开最近与收藏」），收起时页签留着，点「最近」或「收藏」先展开再切过去；收起状态记在设置里（`Home/QuickCollapsed`），重启后照旧；键盘可用 Tab 到达、空格 / 回车切换。收起和展开都有动画，启动区随之下移 / 回位，立绘脚底始终和启动按钮底边齐。设置页「主页快速启动」里数量 0 显示「隐藏」是按类别长期隐藏，和这个箭头无关。卡片从这一排的左缘一张挨一张摆，宽度取名字行和版本行里较宽的一行（196 起、最多 320），名称和版本放不下时各自显示省略号，悬停卡片可看完整名称和版本；收藏、上次游玩各最多 4 张（默认窗口 1024 宽时一排放得下 4 张，更多的会被最后 120 px 的渐隐裁掉；存过更大的值读回来按 4 算）；「当前」只标当前实例，播放钮隐藏时仍保留位置。实例切换弹层、管理页列表里的实例名同样固定字号、放不下省略、悬停看全名；游戏日志窗标题条里的实例名放不下也省略，全名在系统窗口标题里。
- 从主页选择其他游戏文件夹中的实例后，实例管理页的文件夹选中项、页头胶囊和实例列表随当前目录同步。
- 当前实例：只要有实例就一定有一个当前实例（刷新时按 上次启动 → 上次手选 → 第一个 自动挑；当前那个没了（删掉、修复期间暂时滤掉）时顺延到同一位置的下一个，它回来了而用户期间没手选别的就换回它）；只有一个实例都没有时才是「未选择」。
- 账号入口在主页右上角：一颗圆头像 + 名字 + 一行小状态（「微软账号」/「离线」）的胶囊，底色极淡、不描边（浓度按主题定，风景再花名字也看得清），未登录时只写「登录」；它在拖动条下面，不压窗口按钮，900×620 也不挤标题。只在主页上有。点开毛玻璃账号弹层（从胶囊下面弹出）。未登录时是「未登录」+「登录」；已登录时列最后登录的三个账号（当前那个打勾，点别人即切换），下面是「添加账号」「管理账号与皮肤」「退出登录」（退出登录只清登录状态，账号留在列表里）。
- 常规设置、账号与外观、实例设置等采用覆盖层页面；游戏日志、直链下载和实例更新向导采用独立窗口。
- 覆盖层整页、任务详情和账号页打开时，导航轨、顶栏与内容区共用同一层磨砂风景底；对话框与提示卡只轻微压暗背景，风景仍透出。游戏日志窗同样铺磨砂底，标题旁徽标显示「运行中」或退出码（非 0 或崩溃时为红色）。
- 覆盖层单次仅激活一个主页面；新开页面时先收起可收起的旧页面。
- 键盘焦点清晰可见，Tab 顺序自上而下、从左到右；焦点环不改变控件自身几何尺寸。
- 列表和树（实例、服务端、文件页等）带键盘焦点时，当前行有一圈焦点环色的标记，行尾按钮（文件夹、更多、启动、文件页的详情）同时露出，菜单键或 Shift+F10 在当前行弹出右键菜单（实例行是「更多」菜单，组行是齿轮菜单）；鼠标一点标记和行尾按钮收回，只在鼠标悬停的行显示。开关控件可用 Tab 到达，空格切换，键盘焦点时画一圈药丸形焦点环。
- 键盘快捷键：主页没有浮层、弹出层或下拉占着，焦点也不在输入框 / 按钮 / 列表 / 下拉框 / 滑块上时，回车等于点「启动游戏」（按住不放不重复触发，正在启动时不重复启动）；启动走到一半（游戏进程还没起来）时 Esc 等于点启动卡片上的「取消」，进程起来之后 Esc 不动它；F5 等于点当前页那颗刷新按钮（下载页页头、实例文件各页、账号页、实例设置的日志 / 截图 / 存档等页），页面上没有刷新按钮时什么都不做。弹窗里回车等于它的主动作：新建服务端是「创建」，模组预设编辑器是「保存」。
- 输入类控件（输入框、搜索框、下拉框、数字框）的焦点分两档：鼠标点进来只把底色提亮一档、不画线；最后一次输入是键盘（Tab / Backtab / 任意按键）时焦点才加一圈 3px 淡环。判据只有这一条，焦点从藏起来的那一页交接过来不算键盘操作。报错态把那圈换成危险色。
- 输入框宽度按内容定：名字类（实例名、预设名、配置名、存档名）留 24 个汉字、离线账号名 16 个字符、服务器地址 40 个字符、版本号 12~24 个字符，超出在框里滚动；窄窗只缩不溢出，旁边的按钮（添加、检测、刷新）紧跟输入框。路径、网址、JVM 参数、API 密钥、命令、哈希和搜索框保持整行拉伸。登记写法见 `ui/InputSizing.hpp`，`wtfml.input-widths` 扫描各页防回归。
- 数字框不画上下箭头，单位写在框内（MB / 秒 / 个 等），用滚轮、↑↓、PgUp / PgDn 调整；键入越界时回最近合法值。数字框、下拉框、滑条没有焦点时滚轮不改它们的值（下拉框、数字框由应用级的 `WheelFocusFilter` 统一处理，新建的控件自动生效），那一发转给外层页面滚动（鼠标只是路过时页面照常滚）；点进去、有焦点之后滚轮才调值。小整数（0–5）用「− 值 +」步进，内存这类大范围用滑块配小框。
- 下拉框和「文字 + 选项」的触发器都不带右侧小箭头：整块可点，触发器是胶囊形淡底、悬停加深。折叠行整行就是按钮，右侧写「展开 / 收起」。全应用不画右侧小箭头（∨ / › / 树的展开三角 / 底栏朝上的小箭头）：下载页版本树、资源树与管理页分组的可展开行行尾写「展开 / 收起」（13 号次要色）；进下一步的叶子行悬停时行尾写动词（版本树「安装」、资源树「下载」，强调色），不悬停不写。下载页搜索结果行距加大，展开的那一条连同版本子行铺成一张圆角淡底卡片，「收起」在卡片右上角，版本子行不画图标、文字对齐上面的资源名。返回按钮「‹ 返回」在左侧，不算此列。
- 设置页分段页签（启动 / 提示 / 个性化 / 下载）外面不画框，分组只靠底色差；那圈焦点环只在键盘操作（Tab / 方向键）后出现，鼠标点页签后不出现。鼠标点左侧导航换页后，新页第一个控件（「当前文件夹」、下载页刷新钮、智能体页「+」）同理不出现。
- 悬停提示（tooltip）自绘：磨砂玻璃底、圆角 8、内边距 6/10、字色随主题、无箭头无硬边；悬停 500ms 出现，收起后 1 秒内移到相邻控件立即出现，淡入 120ms 并上移 2px。提示只给图标按钮和条目用，文字按钮不出提示。提示出现在鼠标指针右下方并跟着鼠标走，右 / 下放不下就翻到指针左 / 上侧，不出屏；正文最宽 420 px，到了换行（没有空格的长串也断行），字少时框跟着变窄，一行的高度不变。
- 下拉弹层统一：磨砂玻璃底、圆角 14、内边距 6；项高 34、圆角 8、左右内边距 12，悬停淡底，选中是强调淡底加强调字（不画勾不画条）。最多露 8 项（约 300px），超出在弹层里滚轮 / 拖动 / 键盘滚动，右缘一条 3px 细条只在滚动时淡入、停 600ms 淡出，上下各 16px 渐隐；超过 15 项（旗帜图案、附魔）顶上多一条搜索框，键入只留匹配项。弹层宽度按实际绘制的字体量最长选项，并留出文字内边距和滚动条空间；靠屏幕边缘时先把弹层移进屏幕可用区，宽度不超过可用区。弹层从触发器下方 4px 淡入（150ms）。
- 浮层统一为同一块磨砂玻璃：下拉弹层、可编辑下拉框的补全列表、菜单 / 右键菜单、tooltip（含版本列表行尾按钮的提示）、账号弹层、工具页的工具切换浮层、实例设置的两个浮层、智能体页的实例下拉与「⋯」菜单、实例页的文件夹浮层与文件夹 / 分组齿轮菜单、底栏面板与任务中心浮层。窗内自绘磨砂底 + 1px 亮边；Windows 11 且磨砂生效时另挂 DWM 瞬态亚克力，背后的是真模糊。顶层浮层一律无边框 + 半透明（建窗统一走 `Popups::preparePopup()`），圆角外不露直角黑框。Windows 给 `Qt::Popup` 顶层窗画的原生阴影只会按矩形铺，`preparePopup()` 统一关掉它，换成一块跟圆角同形的柔和阴影（点击穿透的透明窗，垫在浮层正后方并跟着它挪、缩、淡入、收起；tooltip 不带阴影）。实例页文件夹浮层里的列表选中 / 悬停是内缩圆角块（和菜单行同一档），列表按行数定高（最多露 5 行，再多在列表里滚），浮层高度跟着内容走；「添加文件夹…」是浮层底部的一行动作（「+」+ 强调色字，悬停铺圆角底）。
- 换页（主导航切页、整页打开与返回〔账号与外观、实例设置等，从弹层、页内按钮进都一样〕、设置页页签、下载页分类、实例设置分栏）的淡入只动内容本身（淡入 + 小幅上抬），底下写回的是换页前后都不变的那层底（含整窗磨砂的半透明着色），全程不垫任何不透明底色，真机亚克力 / 云母下磨砂不会闪成实心；任务中心整页开合的布局过渡同理。
- 主导航切页会先完成切页信号触发的同步更新，再处理待完成的布局并采集淡入首帧。设置页从主导航进入或切换上方分类时，自适应设置行从首帧起就按当前行宽横排或纵排。
- 进出主页时清晰风景层约 250ms 淡出 / 淡入（缓入缓出），露出 / 盖回整窗磨砂；导航轨不动，字色当下就换。淡到一半又切回去时从当前透明度接着走。
- 开程序「雾散开」：首帧只画磨砂底，首帧之后约 0.6 s 内风景从磨砂里淡出来（520ms），问候、角色、当前实例、启动行依次上浮 18px（带弱回弹）淡入，标题栏品牌 W 写一遍，启动按钮柔光最后亮起；不推迟首帧，动画中照常可点。关程序时各项确认之后内容淡进磨砂并下沉 8px（120ms），再交给 Windows 自己的关闭动画；只动窗口里的内容层，不改整窗透明度和窗口矩形，四档材质同一条路径。窗口不可见、最小化、关机注销时直接关。实现在 `ui/WindowMotion`。
- 加载态统一走 `LoadingState`（下载页资源列表、资源版本层、加载器版本树、预设详情、资源详情页版本列表、预设应用的计划那一格、实例更新向导的加载器版本框、新建服务端的加载器 / 安装器版本框、实例文件详情那一行、下载页「游戏」页头刷新、安装页「实例预设」弹框的右栏与模组兼容检查）：开始后 150ms 还没结果才出现，之前到了什么都不出；出现时三颗主题色的点（一轮 1200ms、错开 160ms）+ 一句话，淡入 250 / 淡出 200；整块盖在列表正中、透明底不拦鼠标，结果到了加载态淡出、内容淡入；行内顶替那一条子行、同缩进。取不到时整块是断开的云 + 原因 +「重试」次按钮，行内是同一图标 + 原因 +「重试」文字按钮，点了重发同一个请求。挂在比 48px 矮的控件上（下拉框、一行字）时画成一行：点 + 话从那一格原来的字起点开始，出错时「重试」是文字按钮。新建服务端只有真发了请求的档位才出加载态，不发请求的档位版本框里不写「正在获取」。下载页「游戏」刷新时版本树照旧挂着，筛选条右边一行「正在刷新版本列表…」，没取到时旧清单照旧留着、这一行撤掉。安装页「实例预设」一点就弹框，右栏先挂加载态，候选读回来再摆；预设文件夹读不了时是出错态 +「重试」；弹框开着时再点不起第二张。模组那一类兼容检查没查完时，选着那一行的行尾是点 + 「检查中 n/m」，查完换成结论。
- 设计系统默认生效（`ui/DesignDefaults`，样式 polish 时自动补上，新写的界面不用记得接）：列表 / 树 / 表还挂着 Qt 自带代理的，悬停 / 选中换成内缩圆角淡底（和侧栏同款，不画竖条），行高不低于 32，表格不画网格、关掉左上角那颗角按钮、表头字跟着那一列的对齐走（数字列靠右，其余靠左；表头本身无底、次要色），表头每一节的内边距和每一格文字的起点是同一个数（`DesignDefaults::cellTextInset()`），首列、中间列、末列的表头字和格里的字对齐，带展开箭头的树第一节表头让过缩进，自家代理的表（预设游戏设置、服务器列表）同样对齐；列表、树、表和多行文本框一律无边框、底透明，多行文本框和输入框同一种输入面；任何 `QStackedWidget`（含选项卡里那一层）换页都有淡入上抬，同一拍里重复触发只播一次。下拉 / 补全弹层和自家代理不受影响。真要原生样子的控件挂 `wtfmlNoDesignDefaults` 属性退出，每处写一行理由（目前只有顶层选项卡：它自己接换页动效）。
- 整页上弹出提示时，提示背后仍是那一页和整窗磨砂：主页风景不回来、不透出底下的主页；换页过渡还在半路时先收到终点再弹。
- 删除等危险操作的确认提示按最宽的按钮文案统一同排按钮宽度；危险按钮仍用危险色，默认按钮由确认流程决定。
- 几处"读盘 / 解码"在后台做，点下去界面不等它：版本清单从网络回来时重扫实例目录、安装页「实例预设」弹框取候选、截图页的缩略图解码。结果回来之前界面保持上一次的样子（预设弹框例外：先弹框、右栏挂加载态）；截图那一页的行高一开始就按有图占好，图回来只换内容。
- 动效始终开启，不提供关闭开关，**不跟随 Windows 的「动画效果」**。

### 主题与尺寸

- 主题配置为应用级，不按窗口分别存储。
- 内置三个具名预设：暮色雪山（出厂默认，主题色 #B7B3EE）、冰川碧湖、落日海崖；另支持「跟随系统」。主题色默认跟着预设那一支走。
- 新安装的整窗材质是风景底（每套主题按自己的内置风景铺），≤ 2 线程的机器和旧版关过「磨砂效果」的仍出厂纯色；盘上选过材质的照原样读回，不受影响。
- 主题支持调整：主题色、文字不透明度、四个语义色、整份导入/导出及恢复默认。
- 背景图只有一张（铺满整窗，主页 / 管理 / 下载 / 设置都在它上面）；支持铺满、完整显示、拉伸、平铺及不透明度调节。「当前图片」显示文件名，超长时省略，悬停可看全名。
- 主题色、选中态、悬停态、焦点环、禁用态统一从 `ui/Theme` 的令牌与调色板派生。
- 选中样式统一为「强调淡底（accent-soft）+ 强调色字」，导航轨、列表、会话栏、实例设置分类都不画左侧竖条；导航轨选中块是圆角 10 的淡底，切换时滑动。
- 滚动条采用细线无槽底设计，把手为胶囊样式；文字型页面预留常驻滚动条空间，防止布局抖动。
- 间距遵循三档规范（页面 20 / 区块 16 / 控件 8）；圆角遵循四档规范（控件 4 / 按钮 6 / 主表面 8 / 小节 10）。
- 字阶四档（`Theme::TextRole`）：页标题 26 手写体 Light · 小节标题 16 半粗 · 正文 / 标签 / 按钮 / 导航 14 · 辅助 13（说明、单位、数值、分组头）。「安装」「创建」「应用」这类主按钮同样是正文 14 系统字（Medium），左右内边距 20、最小宽 88（`Theme::primaryButtonPadX()` / `primaryButtonMinWidth()`），图标档主按钮不吃这条。工具箱也收进这四档：结果标题与预览大字 16、MOTD 与等宽结果 14、说明与色点字母 13。例外：品牌 30、主页大标题 50（窄窗 40）与实例名 40、空状态大字 22。
- 正文用系统字（真桌面上是 Qt 取的系统界面字体，中文 Windows 为微软雅黑 UI，西文和数字也是它）。手写体只用在四处：品牌「WTFML」（Dancing Script）、主页大标题（纯英文名字和「WTFML」用 Dancing Script）与英文副句、页标题（「设置」「管理」、账号页、任务详情等）、空状态大字；这些控件挂 `wtfmlDisplay=true`，由 `Theme::markDisplay()` 统一设。导航、按钮、胶囊、分段、小节标题、表单、列表、菜单、下拉、tooltip、对话框标题与正文一律系统字。

### 高级配色

- 入口：设置 → 个性化 → 底部「高级」展开行 → 高级配色中的「细分区域与控件颜色」，默认折叠。
- 控件角色：支持单独指定控件角色的颜色，可随时点击「跟随主题」清除单项覆盖。
- 界面区域：支持分别调整各区域的底色、文字颜色和文字不透明度；不透明度支持跟随全局；遮罩区域禁用文字设置。
- 配色重置：「重置此区域配色」仅清除当前区域的颜色与文字不透明度，保留背景图及其适配方式与不透明度。
- 生效规则：配色修改即时生效并持久化；无自定义项时使用主题原有色彩；控件角色与局部区域覆盖发生重合时，局部区域覆盖优先级更高。
- 实现结构：实现位于 `ui/ThemeAdvancedEditor.*`，页面放置入口，由控制器负责颜色计算、实时应用与持久化；自动化测试覆盖枚举完整性、折叠状态、颜色编辑、重置保留背景图与异常索引防护。

## 3. 账户与外观

- 支持微软正版登录与离线账号；账户表支持保存多个账号并自由切换。
- 微软登录默认使用 WTFML 的 Microsoft Entra 应用。OAuth 回调、令牌刷新与错误处理集中在认证层。应用注册未获 Mojang 审核通过时，界面明确说明原因。
- 微软登录使用系统浏览器。每次登录由系统分配一个本地回环端口，启动器自动接收结果。授权强制使用 S256 PKCE，回调校验本次随机 `state`。详见 [微软登录安全边界](features/SECURITY_BOUNDARIES.md#9-微软登录回调)。
- 离线账号仅记录显示名称，不生成登录凭据，不能伪装正版在线状态。
- 账号与外观页的账号列表每一行显示自己的头像和来源（微软账号 / 离线账号）；选中行行尾有「切换」「复制 UUID」「删除」。列表下方的「添加账号」按钮弹出菜单：选「微软账号」直接打开浏览器登录，选「离线账号」就地展开名字框 +「添加」。刷新令牌失效的微软账号，来源那行改为危险色的「需要重新登录」，行尾（选中时在「复制 UUID」左边）有「重新登录」，走和「添加账号 → 微软账号」同一条浏览器登录；登录成功后标记清掉、列表自动刷新。点主页右上「登录」只进这一页，不自动拉起浏览器。
- 构建没配微软登录应用 ID 时，「添加账号」菜单里的「微软账号」置灰，悬停显示原因。
- 账号页按账号缓存最近取得的披风列表，两分钟内再次打开或切回时直接复用。缓存到期后先展示已有列表，再后台更新。加载期间仍可操作账号或选择已有的披风，贴图沿用本地缓存。更新失败时显示原因和「重试」，保留当前账号的列表。
- 皮肤与披风支持查看、上传与恢复默认；离线账号支持手动导入本地皮肤。离线账号没有手选皮肤时，预览用游戏会分配的默认皮肤，算不出来（没选实例、加载器实例 JAR 里没有原版贴图）则显示内置 Steve，不再随机抽取；预览下方一行小字说明本地皮肤只在启动器内显示、游戏内按名字分配默认皮肤。
- 账号与外观页展示当前身份、账户列表、3D 预览和操作入口；页宽 ≥860（如 1280×800）三栏：账号 | 立绘 | 皮肤披风；中宽（最小窗 900 宽就在这一档）两栏：左栏自上而下账号、皮肤、披风，右栏立绘随剩余宽放大（最大 288×432），皮肤、披风不用滚动就能看全；再窄（窗口最小宽下到不了）才整列上下堆叠。
- 账号与外观页左栏：页签下面先是账号列表（一个账号都没有时整块收起、不占位），再是入口，间距 8；「未登录」只在页头副题说一次。1280×800 三栏下左栏宽 372，正版说明最多两行、离线名字框（252）+「添加」一行放得下。
- 整页开页前先把排队的布局落定再淡入：淡入第一帧就是最终版面，首次打开不挤、再次打开不跳。
- 账号删除、切换与登录失败均提供明确结果提示，失败不改变已有状态。

## 4. 文件夹与实例

- 支持配置多个游戏目录；当前目录决定数据目录、实例列表及下载保存路径。
- 默认文件夹不可用且存在其他有效文件夹时自动隐藏；唯一入口或当前使用目录始终保留。
- 实例具备稳定身份 UUID，显示名称与实际目录名解耦；改名不丢失收藏、分组与历史启动记录。
- 实例分组支持新建、重命名、排序与删除；删除分组不影响内部实例。分组设置页左右两张小节卡片：左边「分组」清单（标题行右头「新建分组…」，行尾无框上 / 下三角调顺序，按住 Shift 直接到顶 / 到底，底下一句次要色说明），右边以选中那一组的名字作标题（右头「重命名…」「删除」），下面「默认展开」「设为收藏组」两条设置行、开关在行尾；开窗默认选中第一组。底栏左边「恢复默认分组」是只有字的次要按钮（这页只改工作副本，按「取消」整页作废，真恢复前另有一问），右边取消 / 确定。
- 实例操作支持：启动、详情、重命名、更换图标、复制/移动、收藏、删除、导入/导出整合包。
- 删除实例将整个目录移入 Windows 回收站（无法移入回收站时直接报错，不执行永久硬删除），且必须二次确认；运行中、安装/导入/复制/备份/还原中或正在体检的实例禁止删除。
- 复制/移动/导入/删除等文件操作针对同一实例互斥；后台任务提供进度报告与协作取消支持。
- 实例列表展示自定义名称、真实版本、加载器类型及状态。
- 启动与升级提示基于实际版本、依赖和模组规模的即时检查结果。

## 5. 实例设置与文件

实例设置采用可滚动覆盖页，按功能划分子页。页眉的实例名字号随名字长短在 26–20 里取放得下整名的最大一号，到 20 还放不下才省略、悬停看全名；页眉高度不随名字变，改名后重挑。

- **概览与启动设置**：概览提供基本身份、最后启动时间与累计游玩时长，游玩时长可重置；没启动过写「从未启动」。启动设置管理 Java 路径、内存分配、JVM 参数与窗口模式（左边固定宽的行名、右边控件，「跟随全局」说明进悬停提示）；维护功能（复制、快照、修复）集中在维护页。
- **文件管理**：支持模组、资源包、光影、数据包、存档、原理图等分类管理；提供搜索、批量选择、删除、详情查看与打开目录；启停状态仅对支持该机制的类型生效。文件列表无边框，每行两行字（名字 + 大小·时间）居中，悬停 / 选中铺圆角淡底；行尾删除是次要色垃圾桶，悬停才变危险色。资源包等紧凑页头的页，状态筛选那一排按页宽决定跟在搜索框后面还是独占一行，查完更新冒出「可更新」时列表不下移。
- 实例列表的副行显示已有记录的累计游玩时长。主页「最近」和「收藏」显示超过三张卡片时，从末尾将排不下的卡片收窄为图标和启动按钮。
- **拖入文件**：模组、资源包、光影、数据包拖进主窗口时，共用一次目标选择。选中实例时，按文件类型存到对应子目录。选中其他文件夹时，直接存到选定目录。整合包走导入流程（选游戏文件夹、问实例名）；`.nbt` / `.litematic` / `.schematic` / `.schem` 打开原理图预览。
- **文件页按需构建（优化打开耗时）**：
  - 实例设置对话框优化首次打开耗时：文件管理中的 8 个子文件页（InstanceFilesPage、配置文件编辑器、资源包页、存档世界设置等）仅在首次切换到对应页时才构建内部控件，构造阶段仅保留导航与堆叠外壳；
  - 提前到达的接线数据（如 `configFilePage()`、`resourcePackPage()`、图标、资源链接、可更新列表）先记账，建页时自动补灌；设置页打开耗时由 ~130 ms 降至 ~10 ms。
- **大列表绘制**：
  - 文件管理八页（模组、资源包、光影等）的每一行由列表代理直接画出（图标、名字、大小·时间、启用开关、删除），不再一行建一套控件，打开页面不卡顿；外观与悬停、选中、右键、筛选、键盘上下、拖出文件、读屏读名字和开关状态都和原来一致；
  - 模组、资源包、数据包和光影包优先显示包内图标。支持 Fabric、Quilt、Forge、NeoForge、旧版 Forge 的图标声明及 `pack.png`，禁用文件同样读取。后台先显示本地图标，再查询平台身份；本地图标缺失或解码失败时使用网络图标补充，网络图标不覆盖本地图标。
  - 刷新只换列表数据，滚动位置不跳；目录大小等统计后台补填，配备目录统计缓存。
  - 实例文件列表拖拽期间保持行内容可见，拖拽结束恢复原选择与滚动位置。
- **模组操作栏与更新检查**：进入实例模组页自动在后台检查资源更新，全部完成后在任务中心统一提示不完整结果，逐项原因保留在详情中；相同实例的连续相同结果不重复通知，不弹窗或跳转。模组操作栏宽窗显示单列图标与文字，窄窗显示单列图标并以悬浮提示说明操作。
- **配置编辑**：提供 `options.txt` 等文本配置的只读预览与修改；保存前执行格式校验，未修改行与未知键原样保留。
- **世界设置**：支持对单份存档调整游戏规则；修改前自动备份，保存后回读校验。页眉面包屑写「返回 / 世界设置：<世界名>」，点「返回」回存档列表，页里不再有第二个返回；重命名、打开文件夹、整份存档备份、恢复、打开备份目录和删除世界放在同一排。「保存」在「修改存档文件」折叠框里，展开时先问「取消 / 先创建备份 / 继续修改」，取消后折叠行恢复为「展开」。没写进存档的规则在名字右侧标「未写入」，值是游戏默认值，改过才会写入。
- **截图、原理图、结构与回放**：支持多选、全选、反选及清除选择，批量复制、同卷移动或移入回收站，不覆盖同名文件。每批至多 128 项，复制上限 512 MiB。删除前的确认框写出文件名：只选 1 个时写那一个，选 2 个以上逐行列出前 5 个、其余用「另有 N 个文件」收口；取消时选择原样保留。操作结束后按路径恢复仍在盘上的选择与竖向滚动位置（列表变短就夹到新的最大值），删掉的那几行不会顺手选中别的行，搜索过滤状态不变，并报告成功数和失败原因。结构页的来源是各存档 generated 下的 nbt 文件，复制和移动落到目标文件夹的一层，所选文件重名时整批拒绝。原理图和结构页的材料清单、列表下方的「最多的方块」优先显示实例本地游戏资源提供的中文方块名，缺少翻译时显示方块 ID。
- **存档与服务器列表的批量操作**：存档页支持多选、全选、反选与清除选择，批量复制到文件夹或移入回收站（删除前列出世界名确认）；游戏运行中不操作存档，给出提示。服务器列表支持多选批量删除条目，一次读写 servers.dat，任何一条认不出就整批不写；编辑、加入、收藏只在恰好选中一行时可用。操作失败后选择保持，剩下选中的就是没处理成功的。
- **日志与崩溃报告**（实例设置 › 维护 › 日志）：两档共用一页，按修改时间从新到旧。单击一行，列表下方显示文件名、修改时间、大小、行数（行数在后台只对选中的那个文件计算，`.log.gz` 先解压）。双击在启动器内置查看器里打开（复用游戏日志窗：分级染色、级别筛选、搜索、行数上限、导出），右键打开所在目录，查看器菜单里有「用外部程序打开」。按文件头 `1f 8b` 认 gzip，不看后缀；读文件与解压在工作线程。查看器标题与顶端写文件名，不显示运行状态；超过 5000 行默认只显示末尾，可用右上角行数上限切到「全部」（分批上屏）。单个文件最多读末尾 32 MiB。两档带和截图页相同的批量工具条（全选 / 反选 / 清除选择 / 复制到… / 移动到… / 删除），不按后缀判断，目录里的任何文件都能批量操作。
- **游玩时长**：只统计由启动器发起的本地客户端进程，按实例累计，同一实例并行运行的重叠时间只算一次。运行列表显示本次和累计时长；实例概览显示已保存的累计和最近一次时长。
- **资源包**：启用与排序状态直接写入 `options.txt`，支持从排序模式切回文件管理。
- **服务器列表**：维护 `servers.dat` 的读写，支持添加、编辑、删除、延迟检测与直接连接；收藏列表独立保存在 `Servers/Favorites`，跨实例按服务器地址共享，不改动 `servers.dat` 原文件。主机名大小写与 IPv6 写法标准化；状态列仅展示延迟与在线人数，服务器版本与在线玩家浮动展示。地址列显示填写的原文（不补默认端口），过长时省略中间并保留端口，悬停看完整地址；设置页「外观」的「隐藏服务器地址」（`Look/HideServerAddress`，默认关）打开后，域名只显示每段首字母、IP 只显示前两段，悬停提示不再显示完整地址。右键整行弹出「加入」「编辑」「复制地址」，前两项与列表下方按钮同一处理，复制的始终是完整地址，并在鼠标旁提示「已复制服务器地址」。
- **备份管理**：提供世界备份与完整实例快照；清单生成、打包与还原逻辑分离，产物明确可定位。
- **复制暂存机制**：复制实例先拷贝到 `versions/.wtfml-staging/<uuid>`，完整拷贝并重命名 jar/json/meta 成功后再原子发布；失败仅清理当前暂存，不影响已有数据。
- **原地升级保护**：扫描、副本校验与快照校验共用协作取消位；大文件按 1 MiB 块检查取消，取消或关窗停在最近安全点，源实例与用户文件保持完整可重试。
- **统一文件操作报告**：世界导入、迁移/升级副本、单文件拷贝与批量文件操作共用结构化报告：记录逐项结果、同名冲突策略（取消/跳过/覆盖）、可续暂存与失败原因；中断时可在任务中心选择「继续未完成操作」，失败时写出 `<报告>.failure.txt`；自动清理仅处理匹配自身 UUID 的暂存目录。
- **状态保护与互斥**：实例运行中或执行复制/备份/还原/安装期间，文件页禁用启用、禁用与删除操作；批量操作期间将实例标记为忙碌。
- **还原与中断恢复**：还原操作先校验候选目录再执行原子替换；启动或切换目录时保守恢复中断事务，源目录与候选目录同时存在时双方均予保留。游戏根目录整体移动时，通过升级 journal 根指纹重新验证后再恢复。
- **人工恢复目录**：在实例快照的「检查中断恢复」中提供「用旧目录替换（两份都保留）」，详见 [MANUAL_RECOVERY.md](features/MANUAL_RECOVERY.md)。
- **体检**：提供文件完整性校验报告，缺失文件、校验失败文件与未知文件分别列出，仅在具备可靠来源时提供修复方案。

文件页通用约束：

- 模组兼容性判定必须依赖平台元数据或本地文件解析依据。
- 删除、覆盖与移动操作必须二次确认；取消操作必须清理中间暂存。
- 执行操作前重新核对盘上文件清单，防止外部变动引发状态冲突。
- 所有路径检查严格防范 `..` 穿越、绝对路径逃逸及符号链接/junction 越界。

## 6. 实例预设

预设用于用户确认后的实例初始化。

- 预设按游戏设置、模组、资源包、数据包、光影包五类独立管理与存储；旧版复合预设保持既有结构。
- 每类支持选择一份预设；旧版预设保持原始数据，不静默变更。
- 安装页「实例预设」弹框标题前是拼图图标（ⓘ 专指详情 / 说明）。
- 游戏设置预设：对 `options.txt` 实施保序合并，覆盖按键、视距、GUI 缩放等选定项，保留未选中键与未知配置。
- 模组预设仅适用于已安装模组加载器的实例，安装前强制验证环境；纯原版与仅 OptiFine 环境拒绝应用。
- 模组预设严格区分项目、发行版、依赖与冲突；前置缺失或冲突时终止应用并明确告警。
- 资源包预设分别报告部署状态与启用状态。
- 数据包预设在无明确目标世界时保持待应用状态，不创建新世界。
- 预设管理支持新建、复制、重命名、删除、从实例提取、计划预览与应用；单个损坏预设不影响其余预设加载。
- 预设读取与清单解析均在后台异步线程执行，频繁切换仅保留最新请求；读取失败给出明确错误原因。
- 计划预览在后台执行只读计算，支持中途取消；实际应用前重新校验目标状态，不直接套用预览旧快照。
- 模组链接与平台 ID 必须解析为稳定项目身份，不支持未知站点及非数字 CurseForge ID。

详细执行边界参见 [PRESETS.md](features/PRESETS.md)。

## 7. 下载与安装

- 支持原版、Fabric、Forge、NeoForge、OptiFine、Quilt 客户端安装；加载器元数据、安装器参数和
  产物核对集中在下载层。
- 版本清单可走官方或镜像源；选择只影响支持的下载类别，不改变安装判据。
- 下载支持并发、限速、代理、重试、断点续传和本地文件复用。
- **重下 = 校验并跳过**：已有文件先按大小/哈希检查，能复用就不重新下载。
- 无可信哈希的远端模组文件不写入；下载完成后必须校验再发布。
- 进度、实际吞吐、剩余时间只进底栏/任务中心；未知总量或断流时宁可不显示倒计时。
- 失败、取消、部分成功分别报告；取消后清理临时文件，不留下半截可执行产物。
- 安装动作是任务中心里的一项，不另起一套进度系统。
- 直链和已接入的实例资源/安装文件批次可在任务中心暂停、继续；原件指纹及最终提交检查
  阻止覆盖外部改动。跨重启先补齐文件，命名安装需再次明确继续，才执行原选择的安装与预设。
  模组预设暂存与服务端文件下载也已接入；恢复核对原选择及目标，失效平台地址重新查询。
  文件补齐后的安装接续校验在后台执行，可取消、拦截重复继续，关闭窗口保留记录；
  校验通过后重新确认恢复条件，才执行安装接续。
  模组预设暂停后恢复时的目录核对也在后台进行，检查期间不重复恢复；外部修改仍要求重新预览。
  安装器/提交不可暂停，重启不自动运行 Java。范围与真机记录见 [恢复验收](archive/ACCEPTANCE_LOG.md)。
  具体范围与验证见 [下载恢复](features/HIGH_SPEED_DOWNLOAD.md)。
- 服务端安装支持原版、Paper、Purpur、Fabric、Quilt、Forge、NeoForge、Spigot（BuildTools）；服务端使用独立工作目录，首次启动需明确同意 EULA。
- **资源详情页的版本筛选**：顶排是「全部」和大版本（`1.21`、`1.20`，取版本号前两段，新的在前）；预发布与新式快照归入所属版本，折不出所属版本的（周快照、旧测试版）放最后一组「其他」。点一个大版本即按它筛，选中的高亮。下面的文件分组（如「Fabric 1.21.4」）默认全部收起，点标题行展开；展开、收起不改变顶排选中的大版本。从实例进来时顶排预选实例版本所在的大版本（1.20.1 → 1.20），并只展开声明过实例那个细版本的分组。顶排折行，窗口窄或宽都不出横向滚动条。分组规则在 `ResourceCatalog::gameVersionSeriesOf()`，筛选在 `versionsForSeries()`。
- 实例模组详情在头卡提供「模组设置」，版本筛选栏始终提供「显示快照版」，也可单按 Alt 切换。从快照实例进入时默认显示快照文件。
- 下载项按已声明的版本和加载器标记不兼容目标。从模组实例进入下载时按该实例的加载器筛选文件。

详细策略与验收参见 [HIGH_SPEED_DOWNLOAD.md](features/HIGH_SPEED_DOWNLOAD.md)。

## 8. 整合包导入与导出

- 整合包 `overrides` 解压支持协作取消，解压过程定期检查取消信号并设置 900 秒安全上限；解压失败不删除既有用户目录。
- 支持常见整合包归档（ZIP、mrpack、CurseForge 导出包）导入；检测到系统 7-Zip 时自动解压 `.rar` / `.7z` 整合包，未安装 `7z.exe` 时给出明确安装指引。
- 导入前解析游戏版本、加载器类型、覆盖层文件并检测潜在冲突。
- 覆盖文件严格实施路径安全检查，解压或复制异常时清理暂存，不生成损坏实例。
- 导出功能完整保留实例配置、模组清单与必要覆盖项；导出包中彻底剔除用户账号凭据。
- MultiMC/Prism 实例导入时合并 patches 补丁链，原包信息保存在 `.wtfml/pack-source`，导出为 Prism/MultiMC 实例时原样带回。
- CurseForge 缺失项记录在实例导入报告中；支持在任务中心打开「补齐文件」，提供本地文件匹配与 SHA-1 校验；补齐后后台重新验证完整安装状态。
- 针对 GTNH 2.8.4 等包含 MCLib AssetDirector 的整合包，导入成功后依据内置清单（`assets/assetdirector/known-sets.json`）自动预取首启所需 1368 个资源对象（约 122 MiB），完成校验后方结束导入，防止首启出现网络阻塞。

格式规范与导入边界参见 [MODPACK_IMPORT.md](features/MODPACK_IMPORT.md)。

## 9. 服务端工作区

- 服务端提供独立工作区，集成控制台、服务器设置、玩家管理、备份与运行状态监控。
- 实例页「服务端」列表与「客户端」列表同一种行：第一行自定义名，第二行「Minecraft 版本 · 端类型 · 状态」；单击进入该服务端的设置，悬停行尾三格为文件夹 / 更多 / 启动（运行中为「停止」，未装好为「修复」），「更多」与右键是同一份菜单，控制台从菜单打开。名字或版本过长时省略，悬停看全文。
- 服务端下载共用底层引擎，但安装逻辑、参数校验与启动行为完全独立。
- 服务端控制台支持命令交互、日志实时滚动、日志导出与进程终止/强杀（强杀需二次确认）。
- `server.properties` 支持可视化表单与原始文本两种编辑模式，保存前校验合法性，写入前自动备份。
- 玩家管理支持读写白名单、管理员（OP）与封禁列表，展示真实配置状态。
- 服务端设置的保存、重置与启动按钮固定在侧栏底部；存在未保存修改时需确认后再行启动，运行中禁止重复启动。
- 确认启动后，任务中心按服务端名称显示启动任务。服务端报告就绪时记为成功，提前退出时显示失败原因，启动期间主动停止则记为已取消。
- 服务器状态检测失败或超时统一显示为“离线/未知”。

## 10. 任务中心与运行输出

- 底栏居中位置提供任务中心总入口；任务面板按进行中、已结束、待处理三类归集。
- 点左栏任务摘要先弹出约 400 宽的任务中心浮动面板（贴在摘要上方）：当前任务带进度与步骤，等待中可上移 / 下移 / 移除，已结束最近四条可重试、可一键清除；点外面、Esc 或再点一次摘要收起，「全部任务」进整页（筛选、搜索、历史、详情、拖拽排序）。整页只有任务列表和详情两列；运行中的进程不在任务中心里，统一从导航轨底部的运行状态入口查看。面板里露出来的失败算已看过，摘要红点随之熄灭。
- 客户端启动在任务中心按已完成的步骤显示进度。解压与 Java 下载的计数占各自一步的区间，等待游戏窗口时停在该步起点。
- 启动时在后台核对客户端、依赖库、natives 和资源，读取并校验实例体检使用的同一份清单。缺失或损坏的文件先补全并复查，补全失败时在任务详情列出问题。
- 任务中心支持按状态筛选、关键字搜索及一键清理已结束记录（清理记录不删除对应文件）。
- 刷新机制：复用内容未改变的任务行控件，保持当前滚动位置；选中详情实时读取最新数据快照。
- 所有长耗时操作（下载、安装、复制、删除、备份、升级、完整性体检等）均统一登记为任务。
- 复合意图（如「更新实例」）仅展示单个父任务，准备核心、下载依赖等子操作以步骤和进度形式体现。
- 任务严格区分 `Pending / Running / Succeeded / Failed / Cancelled` 状态；取消任务不触发失败弹窗。
- 启动任务在游戏进程起来之前也能在任务中心取消（换令牌、准备 natives、下载 Java 运行时那几段都算）：按下去之后启动流程在下一个检查点停下，不拉起游戏，也不再往下写盘；正在下载的 Java 运行时合作式停下并删掉半截压缩包与这一次解出来的目录，不留半个运行时。用户取消的启动任务记 `Cancelled`，不记失败。日志按来源写「启动已取消：启动器正在关闭。」（关窗）/「启动已取消。」（任务中心）。
- 任务中心整页叠层交互：
  - 任务中心支持作为整页提示层（prompt overlay）叠在实例设置等页面之上，开关统一使用整页快照平滑转场；
  - 叠层开启期间保留原设置页与控件状态，再次点击任务中心按钮或关闭时平滑退回原设置页；
  - 面板集成状态筛选、关键字搜索与已结束任务清理工具栏。
- 文件操作异常中断后，详情页提供「继续未完成操作」；无法继续时输出失败报告文件路径。
- 游戏运行输出输出到专用日志窗口，不写入启动器主日志；高频下载进度事件同样不记入文件日志。
- 游戏异常退出在任务中心生成一条记录，并附带诊断分析与错误报告导出入口。

## 11. 设置

给要改设置的人看：设置页的结构、每一项在哪、保存规则。

### 结构

- 一级页（管理 / 下载 / 设置 / 工具箱目录与工具页）标题共用同一个左缘与上沿：距内容区左 38、上 22（`Theme::pageTitleInsetLeft()` / `pageTitleInsetTop()`），换页时标题不跳；智能体页没有页标题，不在此列。
- 页标题「设置」同一行右侧是搜索，下面一行是 4 个分段页签：**启动 / 提示 / 个性化 / 下载**，选中淡底滑块 200 ms 滑动，不画条。没有左侧索引栏和二级目录。
- 表单单栏，最宽 720，在窗口里水平居中，页标题跟着内容列一起居中、左缘对齐。每个分组 = 16 px 半粗标题 + 一层极淡分组底（无边），行与行之间无缝，用缩进 14 px 的一像素底色差分隔。分组底不嵌套。
- 一行 = 左「标签 + 可选说明」，右控件列固定 220 px；内容宽 < 600 px 时整行上下叠放，控件最宽 320。内存条、JVM 参数、字段胶囊这类宽控件始终整行铺在标签下面。
- 900×590 最小窗口下任何页签都没有横向溢出；超出一屏只出竖向滚动条，沿用 S2 细条（滚动时出现，停 600 ms 淡出）。
- 说明默认不写：仅在标签说不清、有副作用或说明为什么不可用时才留一行 13 px 次要色字；其余移成标签旁 ⓘ 的悬停提示。文案口径见 [UI_COPY.md](dev/UI_COPY.md)。
- 少用项收进每页底部「高级」展开行（整行是按钮，右侧「展开 / 收起」，不画箭头，200 ms 展开，标题行全程不位移；世界设置的存档文件框、主题细分颜色、实例设置「启动」的高级选项用同一套开合动效）：「启动」页收 JVM 参数，「个性化」页收语义色、高级配色、整份主题导入导出。
- 页头搜索按标签名或分组名跳到对应页签并滚到那一行；目标在「高级」里时先展开。`MainWindowUI::showSettingsCategory(键, 标签)` 是代码里指向某页 / 某行的统一入口。
- 账号管理不在设置里，入口在主页身份区和导航轨底部浮层。

### 保存

- **没有「应用」按钮**：开关、下拉、滑块、步进器改完即存；输入框失焦或回车即存；JVM 参数框失焦或 Ctrl+Enter 即存（边打字不存，半条参数不会进命令行）。
- 用户改过后右上角淡入一行「已保存」（180 ms 淡入，停 1.2 秒后淡出）；没改过就失焦不提示。
- 需要重启才生效的项在行内用 warn 色小字写明。
- 双进程共用注册表时按键逐项合并，避免旧快照覆盖其他进程的新改动。

### 语言

- 「个性化 → 外观 → 语言」三档：跟随系统 / 简体中文 / English。默认跟随系统 UI 语言
  （是中文含繁体用简中，否则 English）；显式选简体中文或 English 时不看系统。源文就是简中，
  所以简中不装翻译。
- 改动只落盘、不即时换：弹出提示卡「已保存为当前选择，重启启动器后生效」，两颗按钮是
  「立即重启」和「稍后」。立即重启先放掉目录会话锁再起新进程（参数照抄本进程），
  新窗口不会被「同一游戏文件夹只允许一个窗口」挡住。
- 英文（美国）覆盖导航、主页主要操作、世界设置、账号与皮肤、主题、预设、安装和整合包导入等界面。英文译文待精修。翻译和自检见
  [dev/I18N.md](dev/I18N.md)。

### 页签与分组

| 页签 | 分组 |
| --- | --- |
| 启动 | 运行时（右侧「Java 管理…」）· 内存（分配方式、最大内存）· 游戏窗口（窗口模式、窗口大小）· 运行与日志（启动后、游戏日志窗口、进程优先级）·「高级」→ JVM 参数 |
| 提示 | 启动前（Java 版本不符时提醒、重复启动时确认、同一实例已运行时提醒）· 下载时（检查前置模组） |
| 个性化 | 主题（配色、磨砂效果、材质、着色强度、模糊强度、主题色、文字不透明度）· 背景图 · 外观（语言、窗口大小「恢复默认」、日志颜色、隐藏服务器地址）· 主页快速启动（收藏、上次游玩，0–4 个，0 显示「隐藏」）·「高级」→ 语义色、高级配色、整份主题 |

- 下载和拖入资源共用可搜索的目标选择器，可直接选择其他文件夹。关闭「内置目标实例选择器」后这两个入口都直接打开系统文件夹选择框。拖入模组时，加载器或 Minecraft 版本与模组声明不符的实例带提示，仍可选择。

### Java 管理与内存

- **Java 管理**：
  - 提供「自动（按版本匹配）」及各受支持 LTS 主版本（25 / 21 / 17 / 11 / 8）的手动指定；
  - 支持「下载所有缺少的 Java」（从 Adoptium 获取运行时安装至数据目录 `java/<主版本>`）与「检测已有 Java」（重新扫描本机系统路径）；
  - 支持「手动指定 java.exe…」：工作线程异步校验 Java 真实版本，确认无误后方写入配置，校验失败给出明确提示且不改动设置；手动指定的运行时标记为「（当前）」；
  - 首次进入设置页时的 Java 扫描在后台异步进行，目录变更使旧扫描缓存失效。
- **内存**：
  - 手动分配：调节 `MemorySlider` 或数字框，数值直接对应 `-Xmx`，`-Xms` 由启动器结合策略维护；
  - 自动分配：控件禁用并展示根据物理内存动态计算的推荐值（滑条的圆圈与虚条都停在自动值那一格），切换回手动模式时还原此前的手动配置；
  - 自动内存计算逻辑封装在 `GlobalJavaSettings::suggestXmxMb()` / `suggestXmsMb()` 中。

## 12. 工具箱

工具箱是主窗口的第六个选项卡，入口是导航轨底部的「工具箱」（不在顶上五项导航里）：点一下直接进工具箱页，没有弹出菜单；已经在工具箱页时再点一次回到目录。功能定位为即用即走的轻量辅助工具，不长期占用任务中心。

页面分两层：

- 目录页：自适应网格（最小列宽 240，900 宽两列、1280 宽三列），每格 36 图标 + 名称 + 一句用途（≤14 字），无卡片底，悬停淡底；右上角「记住输入」开关，关闭后清除已记住的输入。
- 工具页：页头是面包屑「工具箱 / 附魔助手」。「工具箱」回目录；点工具名弹出磨砂切换浮层（宽 236，复用 `GlassPopover`），直接换到别的工具。没有页内页签。
- 首次打开工具箱只搭目录页；某件工具第一次进去才搭它那一页（灌表、摆回记住的输入、算初值都在这时做），之后一直留着，同一会话里切走再回来输入不丢。没进过的工具，「记住输入」存盘时沿用上一次记住的值。
- 内容宽最大 880，在窗口里水平居中，页标题跟着内容列居中、左缘对齐（智能体「API 与模型设置」同样居中）；工具箱目录和各工具页在最小窗口 900×590 下没有横向滚动条、没有被裁的控件，也都没有纵向滚动条，窄时重排：内容宽 < 640 时附魔行折成两行，纹饰预览挪到输入下面，保存目录与文件名上下叠放，长的一行控件自动折行。数字框、下拉统一高 36。

当前内置工具（目录次序）：
- 附魔助手（计算铁砧经验惩罚与最优合成顺序；每行「附魔 · 等级 · 物品 · 已用次数」四个等高的框，物品下拉含「同上一件」）
- 彩色文本（左侧直接编辑预览，可粘贴文本并为选区应用颜色和格式；右侧 § 源码实时同步，JSON 可粘贴后应用，MOTD 只读；三种格式均可复制）
- 坐标换算（F3+C 剪贴板解析、区块边界、下界/主世界换算；「粘贴命令」直接读剪贴板里那一条 `/execute in … run tp …`，认出维度与坐标当场换算，结果可一键复制成 `/tp` 命令）
- 延迟测试（服务器延迟与 MOTD 检测；下方按地址保留最多 20 条结果，同地址重测更新该行，离开工具清空记录）
- 信标计算（金字塔基座布局；左边结果，右边光柱配色：玻璃清单每行带色点，光柱示意放在柔和底台上）
- 酿造助手（从水瓶起算，结果给产物瓶数、药水名、效果等级与持续时间，瞬间药水改写说明；材料按瓶数与酿造次数备齐，烈焰粉燃料另列；支持 1.21 盘丝/蓄风/渗浆/虫蚀等药水，标示版本可用性）
- 旗帜设计与预览（左边图层卡：选图案与颜色、加一层、旗面预览与清单，右边结果分「步骤 / 材料 / 指令」三段，从选定底色的空白旗帜开始，只列叠加图案的步骤与材料；预览下那句提示独占卡宽，「加载贴图…」在它下面左对齐；标示目标版本图案支持情况；自动适配 1.20.4 及早期的 NBT 格式与 1.20.5+ 的物品组件格式）
- 直链高速下载器（工具页，不再是独立窗口；进度在工具页和任务中心）
- 盔甲纹饰搭配与三维预览（详见下文）

### 盔甲纹饰搭配与预览资源

- 功能入口：工具箱 → 纹饰搭配。材料配方离线计算；三维预览在运行时载入对应纹理。
- 客户端资源扫描：
  - 打开工具时，后台按**客户端所属原版版本的发布时间**由新到旧扫描已安装客户端（上限 16 份），避免因文件解压时间一致而误选旧版本；
  - 继承型或整合包实例通过 `jarOwnerId()` 追溯原版 JAR；整条继承链均无法解析发布时间的版本排至最后；
  - 提供「读取已安装版本」重新扫描按钮与「选择本地 JAR」手动导入入口。
- 预览资源下载：
  - 本机无可用资源时，可点击「下载预览资源」，经确认后从 Mojang 官方下载 Java 1.21.4 客户端 JAR 包（大小 28,335,587 字节，约 27.0 MiB）；
  - 资源仅缓存于当前游戏目录 `cache/preview-resources/java-1.21.4-client.jar`，严格执行官方 SHA-1 与文件大小校验；下载不安装游戏实例、不附带 Java 依赖，不执行 JAR 代码。
- 资源加载约束与超时保护：
  - 资源包下载总超时为 600 秒；
  - 归档解压与读取单次超时为 30 秒，并对读取条目总数、解压体积及图片分辨率设置上限保护；解压内容在内存中解析，不向游戏目录落地未受控临时文件。
- 三维模型与材质支持：
  - 支持鼠标拖拽旋转、滚轮缩放、双击视角复位；
  - 支持单件盔甲与四件套组合预览，盔甲模型采用空心双面绘制，开口处呈现内侧纹理；
  - 支持 1.20 及以上原版纹理路径规范：1.20–1.21.1 路径（`textures/models/armor`、`textures/trims` 等）、1.21.2+ 装备层路径（`textures/entity/equipment`）以及 26.x 调色板路径（`textures/palettes/trim/`）；自动映射到规范结构；
  - 涡流、镶铆纹饰需要 1.21+ 资源；树脂质纹饰需要 1.21.4+ 调色板；缺失资源时给出明确文字提示；
  - 预览复用当前选中账号的玩家皮肤及纤细（Slim）模型，切换账号时同步刷新。
- 权利说明与验证：
  - 启动器源码、安装包及测试夹具均不分发任何 Minecraft 官方受版权保护的纹理；
  - 自动化测试工程 `wtfml.armor-trim` 采用代码生成的无版权合成纹理测试模型与调色板；
  - 支持通过环境变量 `WTFML_TRIM_TEST_JAR` 指定真实客户端路径，以及通过 `WTFML_TRIM_PREVIEW` 输出渲染截图进行离线核验。

## 13. 网络、更新与诊断

- 通用 HTTP 网络请求基于 `HttpClient`；高速多段下载采用专用传输引擎。超时、重试、代理、Range 分段与错误归类遵循共用网络策略。
- 镜像源与代理设置仅调整请求路由，不降低下载安全校验标准。
- 更新中心支持组件检查更新、按项更新、忽略版本、固定版本与回滚上一版本。
- 更新执行前自动创建轻量回滚点，更新异常时保留原始文件；回滚点提供定向恢复能力。
- 启动诊断工具收集启动器版本、Java 状态、路径配置与关键日志摘要，不收集私有凭据与敏感令牌。
- 网络诊断工具（`WTFMLNetworkDiag.exe`）支持独立运行，可细分诊断 DNS 解析、TCP 握手、TLS 协商、HTTP 响应及数据传输各阶段异常。

## 14. 数据格式与安全规范

- 版本号、核心路径与配置键遵循唯一权威源原则，避免多头定义。
- 实例元数据 `wtfml.meta`、预设结构、安装事务记录与回滚数据严格保持向后兼容性。
- 所有关键文件写入均采用「写入临时文件 + 原子替换」机制，保障写入中断时不破坏已有文件。
- 注册表与配置项读取具备容错机制，缺失项或格式错误项不反向覆盖损坏有效配置。
- 路径防护约束：所有路径处理均严格校验，杜绝以下风险：
  - `..` 相对路径穿越；
  - 绝对路径越界逃逸；
  - 符号链接（symlink）或目录联接（junction）跳出目标根目录；
  - NTFS 备用数据流（ADS）或 Windows 保留设备名称（`CON`、`PRN`、`AUX` 等）。
- 外部输入安全性：版本 JSON 中的资源索引号与哈希值、外部传入的文件名在拼接本地路径前，统一通过安全字符集校验；外部图片解码前预先读取头部尺寸并设置分辨率上限，详见 [SECURITY_BOUNDARIES.md](features/SECURITY_BOUNDARIES.md)。
- 压缩处理与炸弹防御：
  - Windows 压缩后端采用扩展长路径格式，完整支持长路径、中文与特殊字符；
  - `ZipUtil` 压缩炸弹防护阈值：单条解压体积 ≤ 2 GiB，压缩比上限设为 10000（仅针对 > 1 MiB 的条目检测，避免 World region 等合法全零稀疏文件被误拦截），整批累计解压体积 ≤ 16 GiB。

## 17. 历史增量特性归档

### 凭据存储与日志保护

- Windows DPAPI 加密失败时拒绝覆盖凭据，不再回退到旧版混淆算法；保持对历史旧格式的兼容读取。
- 从凭据存储与认证响应中提取微软/Xbox/Minecraft 令牌，在错误信息、游戏输出和导出数据中统一脱敏。
- 正式入口文件日志采用递归互斥锁保护多线程写入与缓存迁移。

### 外部输入名称与图像安全边界

- 对 `version.json` 中的资源索引号、对象哈希以及更新审计表中的文件名在拼接路径前执行合法性检查（`AssetNames`、`InstanceFiles::validateFileName()`）。
- 外部图片解码引入尺寸防御（`ImageDecode::Limits`）：先读头确认尺寸，超限拒绝解码；按图片用途分别设定 1 MP 至 64 MP 不等的防护阈值。
- PowerShell 执行统一使用绝对系统路径 `%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe`，避免因 PATH 或当前目录劫持导致安全风险。
- 详见 [SECURITY_BOUNDARIES.md](features/SECURITY_BOUNDARIES.md)。
- 验证范围与保留证据见 [验收记录](archive/ACCEPTANCE_LOG.md)。

### 性能与交互优化

- 实例设置对话框文件页采用惰性按需构建，打开耗时从 ~130 ms 降至 ~10 ms。
- 任务中心支持作为整页提示层叠在实例设置页之上，采用整页快照平滑转场并保留下层页面状态。
- 大列表（模组/存档）采用 80 行首绘 + 120 行分帧渲染，支持可见范围外控件回收与重建。
- `ZipUtil` 压缩比防御阈值调整为 10000，解决全零稀疏文件误杀问题。

### 智能体（Agent）

导航第五项是「智能体」，启动仍停在主页。当前能力是自由对话 + 锁定实例内的受控文件工具 + 维护工作流（实例体检、崩溃急救、版本升级接入、模组维护）+ 启动器只读/受控写工具 + stdio MCP + 联网搜索/抓取与固定诊断命令；不含任意命令（`command.run`）、资源安装工具和 HTTP/SSE MCP。设计与边界见 [AGENT.md](features/AGENT.md)、[AGENT_STAGE1A.md](features/AGENT_STAGE1A.md)、[AGENT_STAGE1B.md](features/AGENT_STAGE1B.md)、[AGENT_STAGE2B.md](features/AGENT_STAGE2B.md)、[AGENT_STAGE2A.md](features/AGENT_STAGE2A.md)、[AGENT_STAGE3.md](features/AGENT_STAGE3.md)、[AGENT_STAGE4.md](features/AGENT_STAGE4.md)、[SECURITY_BOUNDARIES.md](features/SECURITY_BOUNDARIES.md)。

**聊天**

- 左侧会话栏：新建、选择、搜索过滤、重命名、固定、删除（二次确认；只删会话正文/快照/artifacts，不删文件维护备份）；标题取第一条用户消息，最长 24 字。空会话点 ＋ 不再新建；从没动过的空「新对话」切走即丢。列表按「固定 / 今天 / 更早」分组，空组不出小标题。
- 聊天顶行：标题（双击改名）、API 状态胶囊、实例胶囊、`⋯`（重命名、固定、加密存储、导出 Markdown、删除）、API 设置。系统提示居中显示；输入框为空时提示「Enter 发送 · Shift+Enter 换行」。
- 右侧聊天：流式正文、推理内容折叠、停止、错误/中断提示、重试；Markdown 只允许白名单标签，原始 HTML/script/iframe/远程图片不执行，链接不自动打开。
- API 与模型设置：OpenAI-compatible 基础兼容子集；Base URL、模型、上下文窗口、最大输出、温度、超时、部署类型；枚举化协议适配（认证头、流式、`max_tokens` 字段、system role、reasoning 回传、temperature/tool_choice 省略）；测试连接只报告成功/HTTP 状态/耗时。
- 凭据：Windows 凭据管理器主路径，DPAPI 后备，两条路都失败拒绝保存并保留旧值；默认星号遮挡、不回显；日志/会话/错误不出现明文 key。
- 会话存储：`%LOCALAPPDATA%\WTFML\agent`；元数据与正文分开；默认明文 JSON；会话 `⋯` 菜单可打开「加密存储」，正文改成 DPAPI `.enc`，标题和时间仍为明文；正文 8 MB / 2000 条上限；恢复快照最多 3 份；损坏正文隔离不覆盖。
- 网络：远程只允许 https，loopback http 需显式勾选；不跟随重定向、不忽略证书错误；响应 16 MB / SSE 行 1 MB 上限；429/5xx 首字节前最多重试 2 次。
- 取消：停止、切换会话、切到别的选项卡、关窗都取消在飞请求；流已开始后失败保留部分内容并标「已中断」，不自动重发。

**受控文件工具**

- 实例锁定：第一次实例工具调用锁定当前主页实例并先持久化；锁定后不跟随主页切换；换游戏文件夹/实例删除返回 `InstanceUnavailable`；可在实例下拉里预先选定或改回跟随主页，已有记录时切换需确认。
- `fs.list` 只返回目录元数据（数量/大小/是否截断），不返回文件名；`fs.listNames` 返回完整文件名清单，每次审批，最多 2000 项。
- `fs.read` 只读锁定实例内文本，默认 256 KB、最大 1 MB；二进制/凭据文件拒绝；返回 sha256 + `fileIdentityToken`；大文本写模型可读 artifact。
- `fs.write` 只允许 `config/**`、`defaultconfigs/**`、`options.txt`；必须带旧哈希与身份 token；每次审批；写前 DPAPI 备份、原子替换、写后回读；对象/内容变化拒绝。
- `artifact.read` 只读模型可读 artifact，每次重新脱敏；本地原始存档 id 模型不可读；大文本 artifact 只保存本次读取窗口，不是整个原文件。
- 外发（D11）：日志/崩溃报告/锁定实例元数据/目录元数据自动读取，配置/完整文件名/其他文本逐次确认，凭据文件/凭据存储/二进制硬阻断，严格模式关闭自动读取；自动读取也提示「可能发送给当前模型服务」。
- 审批卡显示目标、摘要、diff/预览、备份提示、外发说明；工具卡显示待执行/执行中/完成/失败；审批请求不存「已批准」布尔，重启后作废并重新请求。
- 维护备份：`owner=agent` / `source=agent-session` / `sourceSessionId` / 实例 id / sha256；删除会话不删备份，只清理 Agent 自有备份。
- 脱敏：键名按 `_`、`-`、`.` 和驼峰切词根，命中 password/secret/token/credential/apikey 或 api+key 等词根时遮值；固定形态覆盖 Bearer、`sk-`、JWT、`AKIA…`、PEM 私钥块；凭据文件名按 dotenv 家族、证书后缀和 credential/secret/token/apikey 词根硬阻断。完整方案见 [AGENT.md](features/AGENT.md) §8.2。

**维护工作流与启动器工具（Stage 2B）**

- 模式胶囊：自由对话 / 实例体检 / 崩溃急救 / 版本升级 / 模组维护。模式记在会话里，换会话跟着会话走；换模式作废旧计划、证据保留。
- 实例体检只读：跑启动诊断、完整性体检、模组统计、日志结尾，结论分级并附证据 id；不写盘。
- 崩溃急救：先按启动器现有规则分类（OOM、Java 版本不匹配、缺前置、文件损坏、配置错误），只按现有规则判断、不猜具体模组；修复必须先用结构化计划卡提交，批准后逐步执行、每步单独审批，最后跑验证步并提交报告。没有证据不能报完成；某步失败后写工具全部锁住。
- 启动器工具：实例清单（默认只给总数）、实例摘要、启动诊断、崩溃诊断、日志结尾、崩溃报告列表、完整性体检、模组列表（默认只给数量）、设置读写（白名单键，`java.path` 只写不读）、Java 列表、内存建议、备份列表/创建/恢复、升级检查、打开升级向导或已有页面。
- 只读工具自动执行，完整实例清单/完整模组文件名/设置写/模组启停/备份创建与恢复逐次审批；拒绝时一个字节不改。诊断结果经字段白名单投影：不带 Java 路径、数据根、日志与崩溃报告绝对路径、原始 stack trace；日志里的本机路径替换成 `<path>`。
- 维护备份支持一次多个文件（config/mods/options/servers），内容仍是 DPAPI 密文；恢复前先做一份快照；只恢复 `owner=agent` 的备份，启动器自己的 zip 备份只列出。

**MCP（Stage 2A，stdio）**

- 只支持 stdio；可执行文件必须是绝对路径，不自动下载/安装，不把 `npx`/`uvx` 当默认。
- 首次启动、配置修改、手动重连前都要确认：确认卡展示可执行文件路径/SHA-256/大小/文件 ID、参数、工作目录、环境变量白名单，并写明「该服务器以当前 Windows 用户权限运行」。可执行文件被替换（路径不变但内容变了）要重新确认；文件缺失直接拒绝启动。
- 不自动重连、不自动重启；崩溃后状态显示失败，等用户手动重连并重新确认。
- 每个 MCP 工具逐次审批（不信任服务器声明的只读注解）；工具结果按不可信数据处理，进模型前遮凭据、16 KB 截断；`isError` 显示成错误。
- 服务器 stdout 只走协议，stderr 进脱敏日志；垃圾行超限终止会话；进程用 Job Object 管，退出/超时清理整棵进程树。
- 环境变量只记名字、只透传父进程同名变量；MCP 工具不进入维护工作流的技能白名单。

**联网与固定诊断命令（Stage 3）**

- `web.fetch`：只抓 http/https 公网地址。解析目标 host 的全部 A/AAAA，任一为 loopback/私网/链路本地/组播/保留地址就整条拒绝；连接**已校验的 IP**，Host 头与 TLS 主机名校验仍用原 host；重定向最多 5 跳且每跳重新解析校验；强制直连不继承系统代理；只读文本类内容，响应 2 MB、正文 20 万字符封顶；HTML 转纯文本并遮凭据。
- `web.search`：用设置里的 SearXNG 实例搜索，最多 20 条；每次调用都要审批（搜索词会发给第三方），摘要同样遮凭据。
- `command.diagnose`：只执行固定诊断命令（`java -version`、`where java`、`ping <host>`、`nslookup <host>`、`netstat -ano`、`ipconfig /all`），host 参数只接受域名/IP 字面量；默认关闭，打开后每次执行仍要审批；进程树随超时/取消清理，输出 256 KB 封顶。
- 任意可执行文件（`command.run`）不开放；联网与命令工具只在自由对话模式可用。

**硬约束**

- 没有会话级目录放行；配置文件每次确认，确认后也只发送脱敏片段；`versions/libraries/assets/java/servers` 原始写一律拒绝。
- 模型不能修改系统提示、API 配置、工具白名单或审批策略；会话默认明文存储但不含密钥，加密只保护本地落盘，发送给模型的内容不变。
- 活动会话删除先取消/等待；文件提交阶段拒绝删除并提示。
- 句柄级路径校验用于降低 TOCTOU 竞争风险；检测到 junction/symlink 越界或文件竞争时阻断并报错。
